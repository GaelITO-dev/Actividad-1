# Actividad 1 - Ejercicios HTML, CSS, JS y Bootstrap

Repositorio con los ejercicios prácticos de la Actividad 1 (Tema 2) de Programación Web. Cada ejercicio pone en práctica un concepto distinto de HTML, CSS o JavaScript.

## 🔗 Sitio publicado

Puedes ver todos los ejercicios en línea aquí:
**https://gaelito-dev.github.io/Actividad-1.--Ejercicios-html-css-js-boostrap/**

## 🗂️ Estructura del proyecto

```
Actividad1/
├── index.html          # Menú principal con enlaces a cada ejercicio
├── ejercicio1.html
├── ejercicio2.html
├── ...
├── css/                # Hojas de estilo de los ejercicios que las requieren
├── js/                 # Scripts de los ejercicios que requieren JavaScript
└── img/                # Imágenes usadas en los ejercicios
```

## 🚀 Cómo verlo localmente

1. Clona este repositorio.
2. Ábrelo con [XAMPP](https://www.apachefriends.org/) colocándolo dentro de `htdocs`, o simplemente abre `index.html` en tu navegador.
3. Navega desde el menú principal a cualquier ejercicio.
